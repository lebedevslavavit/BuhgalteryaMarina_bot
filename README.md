# Accountant Bot — Telegram-бот для бухгалтеров

Бот для отслеживания дедлайнов отчётности и налогов с напоминаниями.

## Возможности

- Добавление компаний/ИП (УНП, название, система налогообложения)
- Добавление дедлайнов по типам отчётов и периодам
- Дашборд со статистикой
- Дедлайны на 7 дней и просроченные — с кнопками "Выполнено" и "Удалить"
- Автоматические напоминания (за 3 дня, за 1 день, в день дедлайна)
- Список компаний с удалением

## Запуск локально

1. Создайте виртуальное окружение: `python -m venv venv`
2. Активируйте: `source venv/bin/activate` (Windows: `venv\Scripts\activate`)
3. Установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и заполните BOT_TOKEN и ADMIN_IDS
5. Запустите: `python main.py`

## Деплой на Bothost.ru

1. Загрузите проект в GitHub-репозиторий (без файла .env)
2. В панели Bothost создайте бота, выберите деплой из GitHub
3. Укажите главный файл: main.py
4. Добавьте переменные окружения:
   - BOT_TOKEN — токен от @BotFather
   - ADMIN_IDS — ваш Telegram ID (через @userinfobot)
   - DB_PATH — accountant.db
   - REMINDER_DAYS — 3,1,0
5. Запустите бота

## Переменные окружения

| Переменная | Описание | Пример |
|---|---|---|
| BOT_TOKEN | Токен бота от BotFather | 123456:ABC-DEF |
| ADMIN_IDS | ID администраторов через запятую | 123456789 |
| DB_PATH | Путь к SQLite-файлу | accountant.db |
| REMINDER_DAYS | За сколько дней слать напоминания | 3,1,0 |
